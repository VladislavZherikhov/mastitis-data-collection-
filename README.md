# 📋 Задачи

## Сева

### 1. Временные окна работы скрипта
- [ ] Добавить в `.env` переменные с интервалами работы скрипта, например:
```env
  MORNING_START=06:00
  MORNING_END=08:00
  EVENING_START=18:00
  EVENING_END=20:00
```
- [ ] Добавить эти переменные в `.env.example`

### 2. Модуль локального диска `local_drive.py`
- [ ] Создать модуль `local_drive.py` с логикой работы с диском
- [ ] Если диск разделён на 2 раздела — попытаться их объединить (не каждый раз через скрипт, а один раз и навсегда)
- [ ] В `config.py` добавить подключение к диску
- [ ] В `main.py` импортировать функции и классы из `local_drive.py`

**Логика работы:**
- Пока занято **меньше 80%** места, файлы пишутся на диск в том же формате, что и в облако
- Когда занято **больше 80%**, удаляются самые старые файлы (например, **10%**)

### 3. Новый формат хранения в S3
- [ ] Для каждого пакета файлов создавать папку с названием в формате `дата_время`
- [ ] В имя каждого файла добавить дату и время (сейчас их нет)
- [ ] *(опционально)* Добавить в каждый пакет `.json` с основной информацией и, возможно, логами

> 💡 Это нужно, чтобы не путаться при выгрузке файлов для обучения моделей.

### 4. Логирование
- [ ] Изучить варианты и подключить логи
- [ ] Предложить, где и в каком формате их хранить (важно понимать, что если их не чистить, они со временем тоже могут забить диск)

### Если юзаешь доп библиотеки, обязательно добавляй их в реки
